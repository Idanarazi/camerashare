# PicMe app (iPhone, Expo)

The native PicMe app. The website lives in the folder above; both use the same server.

**Try it on your iPhone:** install Expo Go from the App Store, double-click `start-app.bat` in the folder above, and scan the QR code with your iPhone camera.

- Screens live in `src/app/` (one file per screen).
- Colors and type: `src/lib/theme.ts`. Settings and dark/bright: `src/lib/settings.tsx`.
- Shared buttons, cards and rows: `src/components/ui.tsx`. Icons: `src/components/icon.tsx`.

The plan, phase by phase, is in the "PicMe Native App Plan" doc.
